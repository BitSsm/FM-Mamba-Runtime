# Third-party components

The readable model adapters and precompiled baseline scans use these projects:

- Mamba2D: https://github.com/cocoalex00/Mamba2D
- Vision Mamba: https://github.com/hustvl/Vim
- VMamba: https://github.com/MzeroMiko/VMamba
- 2DMamba: https://github.com/AtlasAnalyticsLab/2DMamba

Pinned revision records and supplied license texts are retained in `vision_baselines/`. The Vision Mamba initializer is included as readable source. The scan binaries include the existing Windows compatibility changes; the 2DMamba backward adapter uses atomic B/C accumulation across channel blocks.
